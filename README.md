# AI Assistant

Full-stack OpenAI chat product: conversations, Google sign-in, session management, token usage tracking, and billing hooks (billing can be disabled).

## What is in here

- React frontend with Tailwind and a code/editor-style chat UI
- Express routes for auth, sessions, and the OpenAI API
- Token accounting so usage can be billed or capped

## Stack

React, Express, OpenAI, Google OAuth, Tailwind
